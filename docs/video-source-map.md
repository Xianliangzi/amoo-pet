# 视频素材溯源表

Amoo 的六个动作素材在迁移这台设备时散落在三个位置。经过 MD5 逐一比对，三者**字节级完全相同**——它们是同一批文件的三个副本，不是三套素材。

因此仓库只保留 `public/amoo/` 这一份，避免仓库体积白白翻倍。

## 命名映射

| 项目文件名 | 用途 | 中文原片 | MD5 |
|---|---|---|---|
| `eat.mp4` | 喂食，one-shot | 吃饭.mp4 | `ac8ef3187c87ec080a3052264dc44996` |
| `happy.mp4` | 开心 / 靠近回应，one-shot | 开心.mp4 | `6f512ea472bafe5976d1a927e7c11336` |
| `idle.mp4` | 待机，可循环 | 待机.mp4 | `3e60046fa488d226d05587cc4c64ac33` |
| `swim.mp4` | 游动，可循环 | 游动.mp4 | `1b2f8b2d6181e5e0ef53a9ece27afcb1` |
| `play.mp4` | 玩耍，one-shot | 玩耍.mp4 | `729b12369042efdfde66d067dd9c448b` |
| `sleep.mp4` | 睡眠，可循环 | 睡觉.mp4 | `82d5b6cfc84e9da1d517ca56d3b1df68` |

## 原始散落位置

| 位置 | 说明 |
|---|---|
| `public/amoo/` | **权威副本**，代码运行时读取此处 |
| `%USERPROFILE%\Downloads\amoo鱼视频\` | 中文命名的同一批文件，逐个 MD5 一致 |
| `%USERPROFILE%\Downloads\jimeng-2026-10-15-2820-….mp4` | 即梦生成时的原始下载文件名，MD5 等于 `play.mp4` |

上述 Downloads 内的文件为冗余副本，不纳入仓库，可自行清理。

## 尚未生成的素材

策划案第 13 节定义了 8 个动作，目前只有 6 个视频，缺两个：

- `blink` — 0.5–1s 单次眨眼
- `approach` — 1.5–2s 从稍远位置靠近并停住

当前的实现里，靠近回应暂用 `happy` 顶替（见 `src/sensors.ts`）。下一步补素材时应以已确认的 Amoo 主参考图为基础，沿用同一套视觉定义：胖短鱼形、大尾巴、半透明果冻材质、橙黄主体、粉橘渐变、橙红尾部、柔和内发光。
